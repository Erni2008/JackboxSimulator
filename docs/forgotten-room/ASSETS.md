# THE FORGOTTEN ROOM: картинки

Логика и сервер уже работают с любым фоном и любым набором предметов. Здесь описано, какие картинки нужны и в каком виде, чтобы они сразу встали в игру.

## 1. Фоны комнат

| Файл | Статус |
|---|---|
| `assets/forgotten_room/rooms/room_01.jpg` («Кабинет при луне») | готов, 24 места размечены |
| `room_02.jpg`, `room_03.jpg` … | будут добавлены |

Требования к фону:
- 16:9, не меньше 1920×1080 (лучше 2560×1440), JPG.
- Мебель пустая: на полках, столе и комоде ничего не стоит. Все предметы игра ставит сама.
- Рама для картины пустая (тёмный холст), если в комнате есть рама.
- Нужны свободные поверхности: полки, стол, комод, подоконник, кресло, пол или ковёр. Чем больше ровных поверхностей, тем больше мест.

Для нового фона я размечаю места в [RoomCatalog.java](../../shared/src/main/java/com/erni/finalanswer/gameplay/forgottenroom/RoomCatalog.java). Код игры при этом не меняется.

## 2. Предметы

Требования к каждой картинке:
- **Формат:** PNG с прозрачным фоном, один предмет на картинку, без тени на земле (тень рисует игра).
- **Ракурс:** спереди и чуть сверху, как камера в комнате. Предмет стоит ровно, основание внизу по центру.
- **Свет:** холодная луна слева, тёплая свеча справа, как на фоне. Без ярких цветов, в стиле фона.
- **Размер:** высота предмета 512 px для маленьких и средних предметов, 768 px для крупных. Пустые поля вокруг минимальные. На экране игра сама уменьшит предмет под место.
- **Варианты одного предмета** делаются с одного ракурса и в одном размере, отличается только то, что указано. Иначе игроки увидят «изменение», которого нет.
- **Повороты** («перевернулся») игра делает сама. Отдельные картинки для них не нужны.

## 3. Звук (по желанию)

Если звукового файла нет, режим просто молчит в этом месте. Путь: `assets/forgotten_room/audio/<файл>.ogg`.

| Файл | Когда звучит |
|---|---|
| `ambience_loop.ogg` | фон комнаты: ветер, скрип (петля 30–60 с) |
| `clock_tick_loop.ogg` | тиканье во время запоминания |
| `blackout.ogg` | свет гаснет (электрический треск) |
| `lights_return.ogg` | свет возвращается |
| `timer_warning.ogg` | последние 5 секунд ответа |
| `submit.ogg` | игрок отправил ответ |
| `reveal_found.ogg` / `reveal_missed.ogg` | разбор: изменение нашли / никто не нашёл |
| `results.ogg` | итоги |

Реплики ведущего озвучиваются его клонированным голосом через `tools/host-tts`.
