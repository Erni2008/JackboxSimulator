# Зарядка дробовика: пять патронов и дозарядка остатка

В Cursed Boxes используется один общий запас дробовика на всю очередь стрелков. В начале сцены воспроизводятся пять вставок патрона. Действие игрока может быть принято сервером во время зарядки, но фактический выстрел ждёт её завершения. Один выстрел расходует один патрон; смена игрока не запускает новую зарядку.

После каждого выстрела сохраняются движение механизма, выброс гильзы и звук контакта с полом. Подача следующего уже заряженного патрона не воспроизводит звук новой вставки. Когда запас исчерпан, загружается ровно оставшееся число выстрелов, до пяти за один цикл:

| Выстрелов | Партии зарядки |
| --- | --- |
| 1–5 | 5 |
| 6 | 5 + 1 |
| 7 | 5 + 2 |
| 9 | 5 + 4 |
| 14 | 5 + 5 + 4 |

После последнего выстрела дозарядка не начинается. Избыточные патроны первой партии не дают игрокам дополнительных выстрелов.

## Интеграция

- `ShotgunMagazine` управляет только локальным представлением запаса. Серверные лимиты и результаты не меняются.
- `ShotgunAnimator.playReloadAnimation(int)` повторяет существующую траекторию оригинального 3D-патрона. Механизм удерживается открытым между вставками, затем закрывается. Одиночный вариант метода сохранён для остальных экранов оружия.
- Счётчик вставок и номер перезарядки позволяют `CursedBoxesSoundManager` воспроизвести `assets/sounds/cursed_boxes/reload_done(bullets).wav` ровно по одному разу на вставку. `reload_done.wav` остаётся звуком механизма. Обычный выстрел, разрушение и гильза сохраняют прежние события.
- В HUD показано `LOADING n / count SHELLS`.
- Сервер добавляет только в снимок ведущего `remainingShotCount` и `presentedShotCount`. Принятая заявка резервирует выстрел один раз; локальная очередь учитывает её до фактического выстрела. Секретные назначения не добавляются в данные телефонов.
- Явно вышедшие игроки исключаются из бюджета дозарядки; временно отключённые сохраняют выстрелы.
- Девятиточечный автоматический тест теперь ждёт окончания принятого, но ещё не начавшегося выстрела: длительная начальная зарядка не перескакивает через цель.
- Оригинальная модель патрона и её материал прогреваются в загрузочном экране. Новые модели, текстуры, потоки и загрузка ресурсов при выстреле не добавлены.

Длительности открывания, одной вставки и закрывания производны от существующего `reloadDuration` (25%, 35% на патрон и 40%). Показана существующая оружейная анимация: новой модели рук или отдельной анимации тела ведущего нет.

## Проверка

```sh
./gradlew verifyProject :lwjgl3:compileDevJava --offline
./gradlew :lwjgl3:cursedBoxesCharacters -PcursedCharacterQA=true --offline
./gradlew :lwjgl3:cursedBoxesFullRoundCheck --offline
# Во втором терминале, пока запущен full-round fixture:
KEEP_OPEN=0 PLAYWRIGHT_MODULE=/path/to/playwright CHROME_PATH=/path/to/chromium node tools/checks/check_cursed_full_round.cjs
```

`ShotgunMagazineCheck` проверяет 1/2/5/6/7/8/9/10/14 выстрелов при 10/30/60/144 FPS, отсутствие лишней дозарядки, сброс, восстановление и маркеры вставки. Аудиотест проверяет пять звуков вставки и отсутствие повторного проигрывания после сброса на покое. Серверные тесты проверяют приватность бюджета, повторные заявки и явный выход.

Нативный девятиточечный прогон прошёл: 5 + 4 вставки, 9 выстрелов, 8 видимых персонажей, 7 целых коробок, отсутствие загрузок ресурсов и компиляций шейдеров в проверяемых игровых кадрах. Диагностический прогон использует GPU fence; он не заменяет сравнение плавности на целевом оборудовании.

Сетевой прогон с четырьмя телефонами также прошёл: два неверно ответивших прячутся, два верно ответивших получают по одному выстрелу; вставлено 5 патронов, выполнено 2 выстрела, осталось 3. Ghost исключён, Puppeteer раскрыт как выживший. Проверены звук падения обеих гильз, прежние звуковые слои и отсутствие дозарядки при смене игрока. Приложение проверки закрыто, порт освобождён.
