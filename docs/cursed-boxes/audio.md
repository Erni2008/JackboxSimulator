# Звук Cursed Boxes

## Реализация

`CursedBoxesSoundManager` — отдельный, принадлежащий сцене менеджер исходных восьми и дополнительных семи `com.badlogic.gdx.audio.Sound`. Он загружает каждый ресурс один раз, предоставляет общий коэффициент режима и шесть категорий, подавляет повторные события, управляет единственным циклом сердцебиения, останавливает звук при reset/pause/hide и освобождает ресурсы в dispose. Статических изменяемых звуковых ресурсов, новых потоков, сетевых сообщений и файловых операций во время игрового кадра нет.

Используется общий `AudioMix.GLOBAL`: пользовательские Master/SFX и существующие категории умножаются на настройки сцены. Старый `ShotgunAudio` не используется в Cursed Boxes, чтобы не дублировать выстрел и механизм; его просмотрщик сохранён.

## Файлы и события

Все восемь исходников найдены в корне проекта. Их побайтово идентичные копии лежат в `assets/sounds/cursed_boxes/`.

| WAV | Событие |
| --- | --- |
| `shotgun_shoot_done.wav` | `ShotgunAnimator.Event.FIRED`, внутри реального `gun.fire()`: тот же кадр, что отдача и вспышка. Подтверждение игрока и прицеливание звука не запускают. |
| `box_destroy_done.wav` | Реальное событие попадания в `CursedBoxesScreen.updateTimeline()`, одновременно с изменением состояния коробки и созданием обломков. Один звук на серийный номер залпа. |
| `reload_done.wav` | `CYCLE_STARTED`, когда начинается существующий помповый цикл. После вставки всех патронов звучит на `RELOAD_CLOSING`. Отдельные инспекционные OPENING/CLOSING сохранены; начало RELOAD звук закрытия не запускает. |
| `773860__mrgungus__12-guage-shotgun-shell-drop.wav` | Первое пересечение границы пола габаритами видимой выброшенной гильзы. На EJECTED звук не воспроизводится. Один запуск на серийный номер гильзы. |
| `reload_done(bullets).wav` | Вход существующей анимации RELOAD в `ShellState.MOVING`, то есть начало движения вставляемого патрона. Простое программное пополнение патронника звука не создаёт. |
| `heart_beating_done.wav` | Единственный loop в ANTICIPATION и SMOKE_APPEARING текущего выжившего. Начало исчезновения панели завершает loop с затуханием 120 мс. Вход — 80 мс. |
| `reveal_sound2(done).wav` | Начало дыма: граница `timings.anticipation` в авторитетной временной шкале survivor reveal. |
| `reveal_done.wav` | Панель полностью исчезает, персонаж уже полностью виден: граница anticipation + smoke + panel. Это ключевой момент раскрытия, а не окончание последующего idle. |

Для повторных событий оружия используется монотонный номер события аниматора; для разрушения — номер выстрела; для гильзы — номер выброса; для раскрытия — отдельные битовые маски уже обработанных коробок. Повторный сетевой snapshot не воспроизводит звуки повторно. При позднем восстановлении хоста старые раскрытия пропускаются; звуковые файлы по сети не передаются, протокол не изменён.

## Устранение исходной задержки выстрела

В исходном `shotgun_shoot_done.wav` заметный сигнал начинается примерно через 329 мс, в `box_destroy_done.wav` — через 145 мс. Вызов play в нужном кадре не устраняет такую задержку самого файла.

`tools/assets/prepare_cursed_boxes_audio.py` сохраняет оригиналы и их полные копии, а для коротких транзиентов создаёт отдельные версии:

- `assets/sounds/cursed_boxes/runtime/shotgun_shoot_done.wav`: удалено 302,250 мс начального почти бесшумного участка.
- `assets/sounds/cursed_boxes/runtime/box_destroy_done.wav`: удалено 132,667 мс.

- `assets/sounds/cursed_boxes/runtime/reload_done(bullets).wav`: удалено 40,625 мс.
- `assets/sounds/cursed_boxes/runtime/reload_done.wav`: удалено 2,917 мс.

Это точные суффиксы исходного PCM с запасом 5 мс перед первым сигналом выше −60 dBFS. Нормализации, ресемплинга, изменения высоты тона, скорости, хвоста или амплитуды нет. Остальные WAV используются полностью. Менеджер загружает подготовленные версии для SHOT, WOOD_BREAK, INSERT_ROUND и MECHANISM; `Cue.sourcePath` сохраняет путь полной копии. Подробные числа записаны в `assets/sounds/cursed_boxes/preparation.json`.

## Громкость

Настройки доступны в `scene.sounds().levels` и легко меняются из кода:

| Параметр | Значение |
| --- | --- |
| master | 1,00 |
| shotgun | 1,00 |
| reload | 0,75 |
| shell | 0,90 |
| wood | 0,85 |
| heartbeat | 0,60 |
| reveal | 0,80 |

Итоговая громкость учитывает общий Master/SFX, master сцены и категорию. Каждый одноразовый cue имеет не больше одного собственного голоса: случайный повтор не накладывает длинный хвост сам на себя. Сердцебиение управляется отдельным handle и плавной огибающей. При выходе, паузе и уничтожении сцены звук останавливается сразу, поскольку сцена больше не обязана получать render для завершения fade. Нормальное прекращение сердцебиения в последовательности раскрытия плавное.

## Ограничения существующих анимаций

1. **Гильза:** текущая неизменённая траектория заканчивается исчезновением через 0,8 секунды. В нативном тесте девяти выстрелов за это время нет ни одного контакта с полом. Поэтому звук падения загружен и подключён к настоящему детектору, но не воспроизводится искусственно при выбросе/исчезновении. `ModularShotgun.visibleShellTouchesFloor()` — только читающий запрос к преобразованным габаритам той же баллистической модели; положение, вращение, длительность и рендер гильзы не меняются. Пол берётся из существующей мировой опоры полки (`origin.y + RIGHT_FOOT_Y`). Для гарантированного слышимого падения при нынешней траектории потребовалось бы продлить/изменить визуальную анимацию, что выходит за разрешённую задачу.
2. **Вставка патрона:** обычный Cursed Boxes использует помповый цикл и программное восстановление патронника, без отдельной видимой вставки. Звук `reload_done(bullets).wav` подготовлен и работает с настоящей уже имеющейся RELOAD-анимацией, но при обычном автоматическом пополнении намеренно молчит. Фиктивная перезарядка не добавлена.

Не найденных WAV нет. Все восемь успешно декодированы нативным backend.

## Проверки

Успешно:

```
./gradlew :core:cursedBoxesSoundCheck :core:check :server:test :lwjgl3:devClasses
./gradlew :core:build :server:build :lwjgl3:classes
./gradlew :lwjgl3:cursedBoxesCharacters -PcursedCharacterQA=true
./gradlew :lwjgl3:cursedSurvivors -PcursedSurvivorQA=true
./gradlew :lwjgl3:cursedBoxesPhoneCheck
```

Последний fixture дополнен настоящими браузерными телефонами через `tools/checks/check_cursed_boxes_browser.cjs` (Playwright). Подтверждены реальные выстрелы, отсутствие исторических выстрелов/попаданий после переподключения хоста, отсутствие ложной вставки патрона, остановка heartbeat после раскрытия, последовательные раунды, прежние двухвыстрельные правила, результаты и возврат в существующую игру вопросов.

Модульные проверки покрывают восемь кешированных Sound, категории/master, выстрел, цикл, контакт, вставку, дедупликацию, единственный loop/fade, последовательность раскрытия, позднее подключение, reset/pause/mute/dispose и сообщения об ошибках загрузки.

Нативный тест: 9 выстрелов → ровно 9 SHOT, 9 WOOD_BREAK, 9 MECHANISM; INSERT_ROUND = 0, видимых контактов гильзы = 0. Все восемь персонажей остаются видимыми, прежний nine-shot тест проходит. Отчёт: `generated/cursed-boxes/characters/audio.json`.

Нативное раскрытие проверяет 0/1/3/5/8 выживших: ровно один начальный и финальный звук и один heartbeat-loop на каждую фактически проигранную последовательность. После завершения loop отсутствует. Сохраняются проверки отсутствия игровых загрузок текстур/шейдеров/статических буферов. Проверены байтовая идентичность восьми полных копий исходникам и точное совпадение PCM двух подготовленных версий с суффиксами источников.

Нативные автоматические проверки используют только локальный тестовый master 0,12; производственное значение 1,00 не меняется. Проверки подтверждают события и успешную работу backend; субъективная громкость зависит от колонок/наушников.
