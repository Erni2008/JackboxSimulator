# The Last Command — разрешение и интерфейс, 30 октября 2026

Добавлены бюджеты backbuffer: LOW — 1,5 млн пикселей, MEDIUM — 2,5 млн, HIGH — 4 млн. Размер CSS остаётся прежним; на больших экранах снижается разрешение 3D. Прежние ограничения DPR сохранены. Это уменьшает число пикселей, но прирост FPS не измерен.

ResizeObserver следит за контейнером сцены. Повторный resize с теми же размерами не перераспределяет буфер; observer отключается при dispose. Диагностика содержит renderWidth, renderHeight и pixelRatio.

Обновлены загрузка и окно результата, добавлены safe-area отступы и статичная загрузка при reduced motion. Декоративная подпись скрыта на мобильном экране, чтобы не перекрывать CRT.

Проверено: npm browser build, git diff --check, реальный Chromium на актуальном Java-сервере (порт 18094). check_last_command_resolution.cjs прошёл: LOW 1498052, MEDIUM 2499640, HIGH 3998720 пикселей при viewport 2560×1440/DPR2; resize только контейнера до 640×480, возврат, мобильный viewport 390×844, dispose и последующий resize без pageerror. Мобильный снимок осмотрен.

Существующий check_last_command_3d_controls.cjs остановился на старой проверке ray picking CODE_PANEL с фиксированной точкой [-.335,.447,.26]: hit undefined. Полная регрессия управления не подтверждена. Первый запуск на уже работающем сервере 8080 также обнаружил HTTP404 для art/panel_lamps.png; актуальный отдельный сервер отдаёт ресурс с HTTP200.
