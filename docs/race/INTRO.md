# Короткое интро «Проклятого забега»

Вступление длится 34–36 секунд (точное время зависит от выбранного формата), затем отдельно идёт отсчёт. Камера непрерывно проходит реальную сгенерированную карту по пространственному сплайну с постоянной скоростью. Во время объяснения Искры камера продолжает движение: демонстрационный жетон сопровождает пролёт. В конце — короткий переход к камере игрока.

Пять сцен: короткое приветствие, цель/чекпоинт, управление, правило текущего формата, редкая Искра жизни. Первую секунду камера открывает карту без речи; после приветствия оставлена пауза в одну секунду. Предыдущие формулировки правил восстановлены. Демонстрационный жетон не участвует в серверном состоянии. Настоящий жетон остаётся редким, появляется только по серверным правилам; он возвращает первого коснувшегося призрака к живым, а не гарантирует спасение.

Сценарий: `web3d/src/games/race/intro-script.json`. Голос — ранее одобренный локальный ведущий. Новый генератор `tools/host-tts/scripts/race_intro_short_vo.py` генерирует каждую реплику цельной фразой, убирает краевую тишину, выравнивает громкость без прежнего окрашивания тембра. Искусственных пауз между предложениями нет. Голос звучит с естественной скоростью. Монтажные зазоры — 650 мс: короткая пауза после завершённой мысли. Генератор измеряет AAC, обновляет JSON и `server/src/main/resources/race-intro.properties`; клиент и сервер используют одну длительность для каждого формата. Предыдущий `race_intro_vo.py` — старый 64-секундный вариант, для текущей версии не применяется.

Искра жизни — единый объект `life-spark.ts` для интро и игры: потёртая железная оправа с бронзовой кромкой, тёмный растрескавшийся камень и сдержанное внутреннее свечение. В фильме реликвия показана отдельным крупным планом в той же WebGL-сцене рендерера; основной пролёт продолжается. Никаких полноэкранных вспышек или орбитальных колец. Форма и эффекты не меняют серверные условия появления и подбора.

Подача фильма: холодная приглушённая палитра, компактные титры, выровненные влево субтитры. Во время фильма спрятаны декоративные солнечные блики и игровые баннеры чекпоинтов. Гоночная музыка на время объяснения отключена: остаются голос и фон окружения. Пропуск и окончание восстанавливают видимость, экспозицию и музыку игры.

## Валуны

Испытание `chase` — наклонный коридор с боковыми нишами. Новый валун выходит каждые 2 секунды; несколько тел существуют одновременно. Янтарный сигнал предупреждает о следующем выпуске. `rolling-stone.ts` считает движение каждого тела с фиксированным шагом 1/120 с: гравитацию, скорость, удар об наклонный пол, боковые контакты, сопротивление качению и вращение. Столкновение с игроком отбрасывает его по направлению скорости валуна. Время рождения и расчёт одинаковы на всех телефонах; назад перемотанный предпросмотр сбрасывает тело корректно.

## Проверки

- `npm run build --prefix web3d`
- `./gradlew :server:compileJava :server:processResources --offline`
- `node tools/checks/check_race_stones.cjs`: физика, зазор, совпадение при 30/60/120 Гц, перемотка, несколько тел, выпуск раз в 2 секунды и удар по игроку.
- `PLAYWRIGHT_MODULE=/path/to/playwright node tools/checks/check_race_intro.cjs`: четыре карты, портрет/альбом, непрерывность камеры, отсутствие ошибок, часы игры, пропуск и сетевой отсчёт.
- `PLAYWRIGHT_MODULE=/path/to/playwright node tools/checks/check_race_stones_browser.cjs`: несколько валунов и сигнал в реальной 3D-сцене.

Просмотр: `/race/?map=1&skin=a`. Отдельное испытание: `/race/?map=1&t=chase&seed=42&skin=a`. Параметр `introAt` предназначен для фиксированных QA-кадров; `format=DARKNESS` выбирает текст в локальном предпросмотре. В сети формат задаётся сервером.
