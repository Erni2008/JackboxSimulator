## Restore and continue Java development

```sh
git clone --branch backup/java-libgdx-final https://github.com/Erni2008/JackboxSimulator.git FinalAnswer-Java
cd FinalAnswer-Java
git switch -c java-development java-libgdx-final-backup-verified
python3 tools/checks/check_java_backup.py
./gradlew :core:check :server:test :shared:check :lwjgl3:assemble :inspector:assemble
npm --prefix web3d ci
npm --prefix web3d run build
./gradlew :lwjgl3:run
```

Use a supported JDK (Java 21), Python 3 and Node.js/npm. The first build needs
Internet access for Gradle, Maven and npm dependencies. `--offline` works only
when the required dependency caches already exist. macOS desktop launch options
are configured by Gradle. On Windows use `gradlew.bat`. See README.md and
PROJECT_MAP.md for the normal room/server/controller workflow.

The Gradle Wrapper JAR, scripts, properties, all six modules (core, lwjgl3,
server, shared, inspector and the root build), browser controllers, TypeScript
browser source with npm lockfile, tools and original source assets are retained.
`assets/runtime/`, `assets/assets.txt` and browser app/audio-test JavaScript bundles
are generated by the documented Gradle/npm builds. Installed audio/model files
under other runtime-named directories are included; they are not build caches.

## Integrity and scope

`java-libgdx-final-files.json` contains sizes and SHA-256 for every tracked payload
file except the manifest itself. Run the verifier immediately after checkout,
before changing files. It verifies bytes, not external dependency availability
or compatibility with every future operating system. The commit also protects
the manifest. Git LFS is not required: no payload file exceeds GitHub's 100 MiB
individual-file limit. Large models between 50 and 77 MiB may produce warnings.

Excluded from this snapshot (existing local files are not deleted):

- `.git`, OS files, IDE state, temporary files, Gradle/npm/Python caches,
  module `build/` directories, generated distribution archives and QA captures.
- `generated/` reports and archives previously tracked were removed from this
  branch's index only; earlier commits retain them. They are reproducible QA
  output, not runtime assets.
- `.env` secrets, credentials, private keys, local.properties and machine-specific
  voice settings/locks. Safe configuration examples and deployment templates stay.
- Private voice cloning references in `tools/host-tts/reference/`, root
  `voice_sample!.wav`, local voice-generation output/models/settings. The reference
  README is retained. Existing installed announcements under `assets/audio/host/`
  ARE included and work without a TTS model or reference recordings.

Private voice reference recordings and the external local Qwen model are needed
only to generate new announcements with the same voice. They are not necessary
to run or modify gameplay. Back those up separately in encrypted private storage;
this public repository intentionally does not publish them. Existing Git history
has not been rewritten or scrubbed; the content scan covers this snapshot, not a
forensic audit of every historical object. No secrets were found by the snapshot
pattern scan; this is not a guarantee about arbitrary opaque binary metadata.

## Git text normalization correction

The original backup commit/tag remains intact. A follow-up backup-only commit
corrects the verifier for `docs/assets/root-image-migration.csv`: Git's existing
`text=auto eol=lf` rule converts its CRLF to LF on checkout. The manifest now
records its canonical LF bytes and the verifier accepts either local line ending.
Java sources and runtime resources are unchanged. Prefer the `-verified` tag;
the original snapshot is also restorable, but its first verifier reports this
CSV line-ending difference. No tag was moved or replaced.
