# The Last Command — питание и свечение корпуса

30 октября 2026.

## Внешний вид

Существующие боковые колбы получили собственное излучение. Маска привязана к их геометрии в мировых координатах и ограничена стеклянной областью, чтобы окружающие трубы, рамки и крепёж не превращались в светящиеся полосы. В этих областях материал имеет неметаллический отклик и меньшую шероховатость. UV и исходные GLB/текстуры не менялись.

Добавлены небольшие ореолы с depth test и индикатор питания у технического шильдика. В MEDIUM/HIGH два локальных PointLight подсвечивают соседний металл; тени у них отключены. LOW использует излучение, ореолы и индикатор без дополнительных PointLight. Bloom, SSR, преломление и новые полноэкранные проходы не добавлялись.

Состояния: тёплый постоянный свет при готовности/работе; краткий зелёный отклик на COMMAND ACCEPTED, красный на WRONG COMMAND; зелёный при WON, красный при LOST. При паузе рабочая подсветка ослаблена. Во время показа последовательности сигналов яркость снижается до 22%, чтобы не конкурировать с игровыми цветами. Состояние READY не считается паузой: стартовая машина сразу освещена. Нет непрерывного пульса и стробирования, включая reduced motion.

## Нагрузка и жизненный цикл

Новая геометрия — маленький индикатор и три sprite-ореола: четыре дополнительных draw calls, 86 треугольников, одна общая процедурная текстура 64×64. Само излучение колб встроено в существующий шейдер корпуса. MEDIUM/HIGH дополнительно оплачивают расчёт двух источников света в материалах. Прирост FPS и VRAM не измерялись.

Постоянная подсветка сама по себе не требует новых GPU-кадров в idle. Смена серверного состояния обновляет цвета. Геометрия индикатора, собственные материалы, текстура и PointLight освобождаются при dispose; общая внутренняя геометрия Three.js Sprite не уничтожается. Индикатор и ореолы не участвуют в ray picking.

## Проверки

- npm browser build и git diff --check.
- Новый check_last_command_power_lighting.cjs, настоящий Chromium/HTTP/WS: чтение framebuffer подтверждает изменение яркости колбы при включении излучения; steady idle даёт 0 новых GPU-кадров; LOW не содержит дополнительных PointLight, MEDIUM содержит два без теней; LOW→MEDIUM→HIGH→LOW возвращает исходные счётчики геометрии и текстур; сигнал памяти приглушает свет; реальные правильный/ошибочный ответы включают соответствующие состояния; reduced motion; mobile; dispose; без JS/shader errors.
- Проверка света сначала обнаружила гонку в fixture повторного PREVIEW_TASK того же семейства: ожидание теперь проверяет новый taskId и readyAt перед вводом. Повтор прошёл.
- check_last_command_finishes.cjs: реальный ввод через стекло CRT, LOW/HIGH/LOW, сохранение задачи, тыльный culling, mobile и освобождение ресурсов — пройдено.
- check_last_command_art_direction.cjs: READY→PLAYING, mobile и очистка сцены — пройдено.

Снимки LOW/MEDIUM и mobile осмотрены: generated/last-command-power/. Отчёт содержит фактическое сравнение framebuffer для колбы; это проверка видимого излучения, не измерение светового потока или физической температуры. Физические телефоны и длительный нагрев не тестировались. Серверные игровые правила в этой итерации не менялись.
