# The Last Command — точный ввод и механический отклик

30 октября 2026.

## Регулятор

Браузерная ручка теперь отправляет ADJUSTER / STEP / +1 или -1. Сервер вычисляет следующий угол по собственному состоянию. Это сохраняет намерение пользователя при устаревшем снимке клиента и устраняет схлопывание быстрых действий в одинаковые абсолютные SET. Поддержка SET сохранена для прежних клиентов и прямого выбора положения. Дедупликация requestId, проверка taskId, готовности и rate limit остаются прежними.

В анимации ручки отделены логический угол (0/45/90/135) и непрерывная цель вращения. Переход 135→0 анимируется +45°, обратный — -45°, согласно существующему циклу регулятора 180°. Серверное подтверждение по-прежнему определяет состояние и очки. При отклонении/потере соединения клиент восстанавливает принятую позицию; повторная отправка STEP автоматически не выполняется.

## Указатель и камера

Потеря pointer capture отменяет жест и отпускает удерживаемую кнопку. Это дополняет pointercancel, blur и скрытие вкладки. Фокус камеры для регулятора, линзы и четырёх маленьких кнопок теперь рассчитан по их реальным точкам крепления; раньше они получали общий ракурс большой кнопки. Плавная дуга, ограничение расстояния и reduced motion сохранены.

## Сигнальная лампа

В расширенной COLOR допускается OFF: теперь цикл RED→GREEN→YELLOW→BLUE→OFF→RED не застревает на синем. Изменение цвета не даёт очка без подтверждения. В LIGHT_MEMORY лампа/панель сигналов доступны только для показа: попытка ручного переключения отклоняется сервером и не создаёт ошибку игроку. Клиент также отключает эти выходные устройства, а во время наблюдения — кнопки ответа. В заданиях store все показанные механизмы недоступны для ввода.

- 213 серверных JUnit тестов, 0 failures/errors: относительные шаги, wrap направления, replay/stale/invalid запросы, diagnostic STEP, полный цикл лампы и read-only память.
