# Организация изображений Final Answer

## Где что хранится

- `assets/` — оригинальные файлы ресурсов, используемые игрой; структура описана в [assets/README.md](../../assets/README.md).
- `assets/runtime/` — создаваемые Gradle уменьшенные копии. Не редактировать вручную.
- `source_assets/` — исходные материалы, варианты и архив импорта. Не используется напрямую приложением.
- `source_assets/archive/root-imports/` — прежние изображения из корня проекта, сгруппированные по тем же назначениям, что и игровые ресурсы.
- `web/` — HTML, CSS и JS браузерного контроллера. Общие PNG не нужно копировать сюда: сервер берёт разрешённые оригиналы из `assets/` при сборке.
- `generated/`, `*/build/` — результаты сборок, тестовые скриншоты и прочие создаваемые материалы; не источник игровых изображений.
- `lwjgl3/icons/` — платформенные иконки упаковки, сохранены на прежнем месте.

Все исходные имена, включая `papper`, `reminise` и `reroll_hocer`, сохранены намеренно. В реестре указаны старый путь, новый путь, SHA-256, категория и совпадающая игровая копия: [root-image-migration.csv](root-image-migration.csv). Контрольные суммы проверены после перемещения.

## Добавление новых изображений

1. Не складывать PNG в корень проекта или рядом с Java-классами.
2. Изображение, которое будет загружаться игрой, класть в соответствующую подпапку `assets/`. Для THE IMPOSTOR выбирать `assets/impostor/{phone,papers,clock,backgrounds,portraits,voting,envelopes}/`.
3. Неиспользуемые варианты/экспортные оригиналы класть в `source_assets/` по назначению. Исторический `archive/root-imports/` оставлять архивом переноса.
4. Новое общее изображение для браузера добавить в явный список `processResources` в `server/build.gradle`; не открывать доступ к произвольным файлам.
5. Обновить загрузчик/URL только если это новый ресурс. Существующие браузерные URL холстов при этой уборке сохранены.
6. Запустить сборку и проверить соответствующий экран. Не редактировать `assets.txt` и `assets/runtime/` вручную.

## Границы изменений

Java-пакеты, сетевой протокол, механики игры, имена и оформление экранов не менялись. Неиспользуемые копии не удалены, поэтому эта уборка улучшает расположение файлов, но не предназначена для сокращения общего размера исходного проекта. Архив не включается в standalone-приложение.

Обновлены пути в `server/build.gradle`, браузерных проверках пергамента/роли, документации холстов. Модули `core/`, `server/`, `shared/`, `lwjgl3/`, `inspector/` остаются на прежних местах.
