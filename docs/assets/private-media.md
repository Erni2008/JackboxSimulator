# Приватные локальные медиа

Изображения, текстуры, аудиозаписи и визуальные captures исключены из Git глобальными правилами `.gitignore`, включая смешанный регистр расширений. GLB/GLTF и Blend тоже исключены: они могут содержать встроенные текстуры. Исходный код, JSON-конфигурации, лицензии, каталог импортов и инструменты подготовки остаются версионируемыми.

Ранее отслеживаемые медиа удалены только из индекса (`git rm --cached`), а не с диска. Локальные `assets/`, `source_assets/`, иконки приложения и результаты визуальных проверок сохраняются. Контроль SHA-256 подтвердил сохранность 926 файлов при переходе.

## Новый клон

Для запуска/сборки сначала восстановите приватные `assets/` и `source_assets/` из своей защищённой копии с теми же относительными путями. Иконки desktop-приложения также нужно восстановить в исходные пути `lwjgl3/`. Подготовленные runtime-копии создаются существующими Gradle/Python-инструментами. Не выполняйте `git add -f` для медиа: это обходит защиту `.gitignore`.

Резервную копию ресурсов следует хранить отдельно в приватном хранилище. Этот переход не создаёт внешнее хранилище и не загружает туда файлы. Gradle wrapper и Java-зависимости не исключались из проекта.

## Ограничение приватности

`.gitignore` и обычный push удаляют файлы только из актуального дерева новой версии. Они **не удаляют** изображения и аудио из предыдущих коммитов, существующих клонов, форков и ранее скачанных сборок. Чтобы ограничить доступ к истории на GitHub, нужна приватность репозитория. Переписывание истории требует отдельного согласования и force-push; в рамках удаления из индекса оно не выполняется. Уже скачанные чужие копии отозвать невозможно.
