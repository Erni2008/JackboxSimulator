# THE LAST COMMAND: интерактивная панель

Реализована компоновка **4 кнопки + ADJUSTER + LIGHT_MODULE**. Вариант с шестью
маленькими кнопками отменён. Центральная большая кнопка сохраняет свой масштаб,
положение, цвет, локальную ось и длительности анимации.

## Реальные ресурсы

Все пути относительно `assets/models/last_command/`:

| Назначение | Файл | Использование |
| --- | --- | --- |
| MAIN_BODY | `box_final.glb` | Корпус и существующие неподвижные оправы |
| BIG_BUTTON_BASE | `hole_final.glb` | Только центральное основание |
| BIG_BUTTON_CAP | `button.glb` | Центральный экземпляр и четыре маленьких |
| ADJUSTER | `adjuster.glb` | Готовая ручка со штоком |
| LIGHT_MODULE | `light.glb` | Готовая лампа с металлическим корпусом |

`adjuster.glb` и `light.glb` перемещены из корня в ресурсы без копирования или
перезаписи. Исходные и итоговые SHA-256 записаны в `panel-models.json`.
Существующие runtime-копии первых трёх моделей не изменялись. Новые GLB, меши,
текстуры и библиотеки для панели не создавались.

Машина загружает ровно пять источников. Четыре маленькие кнопки — `Scene` /
`ModelInstance` от одного загруженного `button.glb`. Они разделяют исходные
меши, карты и CPU-геометрию picking, имея независимые трансформации и материалы.
Ресурсы принадлежат машине и освобождаются один раз при закрытии режима.

## Компоновка и подгонка

Слева сверху вниз: ADJUSTER, красная SMALL_BUTTON_1, зелёная SMALL_BUTTON_2.
Справа: LIGHT_MODULE, синяя SMALL_BUTTON_3, жёлтая SMALL_BUTTON_4.

`panel.json` содержит **отдельные** позицию, XYZ-масштаб, ориентацию и pivot
каждого механизма. Координаты опираются на исходную геометрию отверстий,
проекции поверхности и нормали их стенок; окончательная посадка проверена на
фронтальном и косом видах, а также при нажатии и повороте. Параметры оставлены
доступными для ручной доподгонки неровной авторской геометрии.

Боковые посадочные оси наклонены примерно на 64° от исходной +Y к переднему +Z.
Масштаб каждого малого колпачка — 0.0285, около 35% от центрального 0.081.
Его pivot находится внутри штока: эмаль выступает над гнездом, а существующая
оправа MAIN_BODY остаётся неподвижной. Дополнительные основания не понадобились.
Ход равен 0.10 локальных единиц колпачка, или 0.00285 единицы сцены.

ADJUSTER вращается вокруг своего штока с pivot (-0.019, 0.46, 0.002) в координатах
модели после авторского преобразования узла. Его скрытая часть погружена в
посадку; кольцо корпуса компьютера неподвижно. Наклон исходной лампы исправлен
дополнительным поворотом Z=55° перед её установкой на панель.

## Материалы

Цвет красной эмали запечён в общий albedo колпачка вместе со штоком. Специальный
PBR-атрибут перекрашивает только область эмали, выделенную геометрией и цветом
исходной карты. Сохраняются её яркостная фактура, царапины, нейтральные сколы,
загрязнения, normal map и metallic/roughness. Центральный экземпляр этого
атрибута не имеет. Изменение цвета одной кнопки не меняет соседей или металл.

Лампа также содержит один объединённый материал. Её стекло выделяется маской
в координатах исходной модели вдоль оси линзы; оттенок и эмиссия применяются
только к этой поверхности. OFF имеет нулевую эмиссию. Цвета RED/GREEN/YELLOW/BLUE,
яркость и мигание управляются программно. Латунь и резьба не перекрашиваются.
При вращении регулятора процедурная патина закреплена за ручкой; исходные карты
всегда вращаются вместе с геометрией.

## Ввод и события

ЛКМ на колпачке: нажатие 0.10 с, удержание, возврат 0.15 с после отпускания.
Движение идёт вдоль локальной -Y с deltaTime и плавной интерполяцией.
ЛКМ на ручке переключает следующий детент; поворот занимает 0.18 с. По умолчанию
доступны 0°, 45°, 90°, 135°. Событие выдаётся один раз после фиксации положения.
Экран использует существующий `GameAudio.press()` / `sounds/ui/button_press.mp3`
для щелчка пользовательского поворота и нажатий, без новой загрузки звука.

ЛКМ на линзе циклически выбирает цвет для просмотра API. Индикатор изначально OFF.
Автоматических заданий или игровых условий нет.

Picking проверяет реальные треугольники всех экземпляров, ближайшее попадание,
перекрытие корпусом и область интерактивной поверхности. Старт на пустой сцене
навсегда закрепляет текущий жест за орбитой камеры; пересечение кнопки при
перетаскивании не создаёт нажатие. Старт на элементе закрепляет жест за ним;
удержание не генерирует повторных событий. Заблокированный элемент остаётся
геометрическим препятствием, но не принимает пользовательское действие.

## API будущих заданий

Вызывать из render thread, пока экран открыт:

```java
FrontPanel panel = screen.panel();
panel.onSmallButtonPressed(id -> { /* SMALL_BUTTON_1 .. SMALL_BUTTON_4 */ });
panel.addListener(action -> {
    // sequence(), seconds(), element(), kind(), value(), cause()
});

panel.press(PanelElementId.SMALL_BUTTON_1); // программное удержание
panel.release(PanelElementId.SMALL_BUTTON_1);
Color paint = panel.button(PanelElementId.SMALL_BUTTON_2).color();
panel.setButtonColor(PanelElementId.SMALL_BUTTON_2, Color.GREEN);
panel.setLocked(PanelElementId.SMALL_BUTTON_3, true);

panel.adjuster().setAllowedAngles(0, 30, 60, 90); // 1–32 уникальных положения
panel.setAdjusterAngle(60);
float displayed = panel.adjuster().angle();
float target = panel.adjuster().targetAngle();
int detentIndex = panel.adjuster().position();

panel.setLightColor(LightModule.State.GREEN);
panel.light().setBrightness(.7f); // плавный переход, диапазон 0–3
panel.light().setBlinking(true, 1.2f, .4f); // период и доля включения
panel.light().off();
panel.setLocked(PanelElementId.ADJUSTER, true);
panel.setLocked(PanelElementId.LIGHT_MODULE, true);

var allEvents = panel.history();
var playerSequence = panel.playerActions(); // PROGRAM исключены
panel.reset();
```

Блокировка запрещает пользовательский ввод; программная настройка регулятора и
лампы остаётся доступной. Смена допустимых углов не снимает блокировку. Блокировка
удерживаемой кнопки запускает её отпускание. История по умолчанию ограничена 1024
событиями; лимит настраивается через `setHistoryLimit`. Снимки истории неизменяемы.
Сброс возвращает механизмы и центральную кнопку в покой, цвета кнопок к исходным,
лампу в OFF, снимает блокировки и очищает историю. Настроенные допустимые углы и
подписки сохраняются. В UI доступна кнопка RESET PANEL.

## Проверки

```sh
./gradlew :lwjgl3:lastCommandPanelCheck :core:check :shared:check :server:check --offline
./gradlew :lwjgl3:lastCommandPreviewCheck --offline
./gradlew :lwjgl3:lastCommandPreview --offline
```

Нативная проверка использует пять настоящих GLB и проверяет общность геометрии/
текстур, независимость материалов и анимаций, реальный ray picking всех элементов,
удержание/повторы, блокировки, вращение вокруг pivot и события, произвольные углы,
все состояния лампы, плавную яркость, мигание, сброс и центральную кнопку.
Общий smoke-тест проверяет камеру и повторное закрытие/создание экрана.

Снимки фронтальной панели сохраняются в `/tmp/last-command-panel-off.png`,
`-red.png`, `-pressed.png`, `-yellow.png`, `-blue.png`; общий вид —
`/tmp/last-command-preview.png`. Изменения ограничены THE LAST COMMAND и его
инструментами; правила, ресурсы и сетевой протокол других мини-игр не менялись.
