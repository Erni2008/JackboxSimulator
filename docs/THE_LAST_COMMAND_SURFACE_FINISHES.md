# The Last Command — стекло CRT и отделка поверхностей

30 октября 2026.

Добавлена тонкая выпуклая крышка CRT: сетка 24×12 сегментов, прогиб центра 1,4 мм, положение на 1,5 мм перед текстурой экрана. MeshPhysicalMaterial использует отражение существующего окружения, прозрачность 0,085 и clearcoat. Transmission отключён: отдельного рендера сцены для преломления нет. Это приближённое визуальное стекло, не физическая симуляция CRT.

Стекло добавляет один draw call и 576 треугольников; новых текстур для него нет. Оно не перехватывает ray picking, скрывается с тыльной стороны вместе с дисплеем, а его геометрия и материал освобождаются при dispose. Показания и задания остаются на прежней динамической canvas-текстуре.

У физического материала корпуса добавлен слабый clearcoat 0,12 / roughness 0,42, маскированный существующей цветовой маской покрытия. Цветные поверхности кнопок теперь имеют неметаллический отклик и roughness 0,40; у маски линзы metalness 0 и roughness 0,17. Металлические основания, цветовые сигналы, анимации и исходные GLB сохранены. Преломление, динамические отражения и новые постэффекты не добавлялись. Измерений FPS/VRAM нет.

Проверки: npm browser build; git diff --check; новый check_last_command_finishes.cjs — реальное нажатие цифры на CRT через стекло, LOW/HIGH/LOW без смены задачи, задний culling, мобильный экран, dispose геометрии; HIGH со всеми механизмами и синей линзой; без JS/shader errors. check_last_command_presentation.cjs — контроль загрузки LOW, выдвижения и picking кодовой панели, idle без лишних кадров и desktop/mobile. Скриншоты осмотрены: generated/last-command-finishes/{front,glass-angle,mobile,hardware-high}.png.

Проверка на физических телефонах не выполнялась. Запечённые детали и геометрия исходного корпуса остаются художественными ограничениями; они не заменялись новым моделированием.
