# Полировка двух мини-игр и быстрый предпросмотр

Экран вопросов и вариантов ответа полностью возвращён к исходному оформлению
по просьбе пользователя; изменения desktop-классов вопросов и мобильных
стилей вариантов отменены. Правила, порядок и синхронизация вопросов не менялись.

Сохранённые улучшения:

- CURSED BOXES: `CursedCeremonyHud` — единая верхняя и нижняя композиция,
  масштабирование по размеру окна, имя действующего игрока, состояние оружия,
  выбранный ящик и остаток выстрелов. Отладочные подробности доступны через F3.
  Исходная сцена, оружие и механика выстрелов сохранены.
- THE IMPOSTOR: `EvidenceBoard` — читаемый шрифт, одинаковые колонки,
  контрастные строки, аккуратная нумерация и подгонка длинных подсказок.
  Верхняя панель участников не редактировалась.
- Телефоны: `controller-polish.css` — более читаемые состояния выбора/подтверждения,
  отступы и контраст в двух мини-играх. Стили вопросов возвращены.

## Задержка запуска THE IMPOSTOR

Измеренная исходная подготовка приложения/меню и сцены: 2671 мс, не считая Gradle.
Кроме того, обычный тест запускал вступление 8,35 с. Предпросмотр теперь:

- пропускает вступление по умолчанию (обычная игра сохраняет его);
- не создаёт неиспользуемые меню, экран настроек и генерации комнаты;
- поэтапно прогревает существующие ресурсы четырёх персонажей с видимой загрузкой;
- прогревает первый кадр перед началом тестовой последовательности;
- использует отдельные настройки предпросмотра, VSync/60 FPS;
- больше не создаёт три неиспользуемых шрифта экрана результатов;
- закрывается без ненужной загрузки главного меню.

После изменения: 2193 мс до готовности сцены на тестовом компьютере; 180 кадров,
средний интервал 16,58 мс, p95 17,04 мс, ни одного интервала более 50 мс.
См. `generated/impostor-preview-startup.json`. Это локальный замер,
не гарантия отсутствия задержек на любом оборудовании. Компиляция в него не входит.

Быстрый повторный запуск:

```sh
python3 tools/dev/run_impostor_preview.py -Dimpostor.preview.verdict=tie
```

Скрипт собирает проект один раз (и после изменений исходников/ассетов), затем
запускает Java напрямую без Gradle. Для просмотра вступления передать
`-Dimpostor.opening.skip=false`. Автоматический сбор замера и выход:
`-Dimpostor.preview.startupCheck=true`. Обычная Gradle-команда тоже поддерживается.
