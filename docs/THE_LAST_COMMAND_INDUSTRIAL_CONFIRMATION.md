# The Last Command — подтверждение механических заданий и индустриальная сцена

30 октября 2026.

## Правила

В диагностическом сценарии mechanisms раньше достижение нужного положения рычага/регулятора сразу переключало шаг. Теперь установка меняет только механизм; переход требует PRESS большой красной кнопки и совпадения принятого сервером состояния с целью. Неправильное подтверждение расходует попытку; промежуточные положения при настройке — нет. Инструкции явно требуют подтверждения.

Основная расширенная игра уже проверяла отдельные LEVER/ADJUSTER по красной кнопке; добавлена регрессия для ста seed каждого семейства: все положения без подтверждения дают ноль очков. В механических последовательностях LEVER_SEQUENCE/SHUTDOWN исправлено прохождение промежуточных положений: они не завершают задачу ошибкой. Итоговая кнопка дополнительно проверяет фактические положения всех ранее настроенных механизмов, а не только накопленный индекс последовательности. Один правильный промежуточный шаг не даёт очко.

На CRT показываются текущее положение рычага, угол регулятора и постоянное напоминание о подтверждении. Прямой URL scenario=mechanisms теперь выбирает диагностику корректно. Звук adjuster.wav также срабатывает на принятое изменение угла в расширенной игре, где lastAction не передаётся: используется изменение серверного состояния в пределах того же taskId.

## Оформление

Круглый выставочный подиум заменён прямоугольным стальным монтажным основанием с шестигранным крепежом и жёлто-чёрной разметкой. Цветовая коррекция корпуса усилена в сторону тёмного графитового покрытия с сохранением красных кабелей и светлых металлических деталей. Добавлен шильдик LC-03 / CONTROL UNIT с серией и питанием. Он скрывается при появлении кодовой панели и не участвует в ray picking. Текстура шильдика и разметка генерируются один раз и освобождаются вместе со сценой. Исходные GLB не менялись.
