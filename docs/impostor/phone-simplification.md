# Упрощённый телефонный интерфейс THE IMPOSTOR

- Роль/слово/подсказка показываются сразу. Нет маски, кнопки раскрытия,
  автоматического скрытия при смене вкладки и автоматической справки поверх игры.
- На получении роли — карточка и один графический таймер. Во время ввода —
  компактное напоминание роли, числовой таймер, пергамент и подтверждение.
- Нет повторяющихся инструкций, навигации по этапам и постоянного баннера связи.
  Сообщение о реальном разрыве связи остаётся видимым.
- Справка доступна в закрытом по умолчанию details «Как играть».
- После отправки — одно подтверждение и компактный счётчик готовых слов.
- Во время обсуждения убраны неактивные карточки выбора. Они появляются только
  на настоящем финальном голосовании. Подтверждение выбора сохранено.
- Вспомогательная кнопка выхода стала компактной и не спорит с игровым действием.
- Озвучка первого/второго голоса не вызывается, удалена из активного каталога
  и манифеста. Индивидуальные звуки ударов и количество печатей не менялись.

Изменены web/impostor.js, index.html, controller-polish.css,
controller-presentation.js, final-voting.js, VotingNarration.java и связанные
проверки. Остальные режимы, экран вопросов и правила не менялись.

Проверки: core:check, VotingNarrationCheck, check_impostor_phone_usability.cjs,
check_controller_presentation.cjs (90 мобильных/горизонтальных кадров).
Снимки находятся в generated/controller-polish/.
