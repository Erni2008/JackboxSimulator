# Полная русская озвучка THE IMPOSTOR

В активном наборе **15 реплик**: 14 новых записей и прежняя инструкция о ролях.
Речевая нумерация голосов удалена из сценария и манифеста: удары печатей
сопровождаются только существующими звуковыми эффектами.
Голос: ранее одобренный `final_answer_host_ru_v1`, существующая локальная Qwen3
Base/ICL-модель. Исходный эталон и подтверждённый транскрипт сохранены.
Системный диктор, VoiceDesign, другой голос, сетевые скачивания и генерация
во время игры не используются. Характер подачи определяется одобренным эталоном;
эмоциональные метки сценария не выдаются за недоступные модели instruct-контролы.

| Этап | Реплики |
| --- | --- |

| Первые подозрения | `impostor_suspicion` |
| Последние секунды | `impostor_round_deadline` |

| Финальный выбор | `impostor_final_voting` |
| Перед подсчётом | `impostor_vote_intro_1`, `_2` |
| Удары печатей | Только SFX, без речевой нумерации |
| Ничья / никто не проголосовал | `impostor_vote_tie`, `_no_votes` |
| Перед музыкой раскрытия | `impostor_vote_reveal_intro` |
| После музыкальной развязки | `impostor_outcome_caught`, `_escaped` |

Тексты — `tools/host-tts/config/events.json`, соответствие аудиофайлам/хешам и
измеренные длительности — `assets/audio/host/ru/manifest.json`.
Новые OGG находятся в `assets/audio/host/ru/events/`, оригиналы WAV сохранены
в локальной базе заданий. Готовый переносимый набор для прослушивания:
`generated/impostor-narration/impostor-ru-voice-pack.zip`.

## Последовательность

Один существующий `HostVoiceManager`, одна очередь `VotingNarration`. Следующая
реплика запускается по завершению предыдущей с паузой; речь не наслаивается.
Музыка/атмосфера приглушаются, звуки печати остаются привязаны к серверным ударам.
Слишком поздние реплики, повторные снимки, истёкшие окна и поздние переподключения
не запускают устаревшие инструкции. При быстрых действиях/коротких настройках
неуместившиеся подсказки пропускаются, а не задерживают игровой процесс.

Перед объявлением текст скрыт до фактического завершения реплики ведущего.
Completion callback запускает соответствующий эффект один раз. При раскрытии
личности сначала звучит итоговая реплика ведущего, затем существующая музыка;
на её акценте (3400 мс от реального запуска звука) появляется ник. Превращение
в призрака начинается через 2400 мс после появления имени. Переход в RESULT
сохраняет эту последовательность и не запускает её заново.

Сервер собирает длительности готовых записей в метаданные и оставляет окно
для реплики и музыкального раскрытия. Голоса, роли и победитель не меняются.
Отсутствующая или повреждённая запись освобождает показ; отмена и смена сцены
не позволяют старому callback включить эффект. При позднем восстановлении
озвучка не повторяется. Reduced motion сохраняет порядок звука и текста.

Подсказка отправляется явным Enter либо кнопкой подтверждения. Удерживаемый
Enter, ввод букв и Enter сразу после подтверждения IME не отправляют черновик.
Сервер запрещает загаданное слово также внутри другого слова (без учёта
регистра и различия Е/Ё); отказ не раскрывает секрет импостору.

## Проверки и прослушивание

- Все активные WAV/OGG: декодирование, формат, длительность, конечный сигнал,
  отсутствие клиппинга, хеши; 0 неудачных заданий.
- Все активные игровые OGG реально воспроизведены нативным libGDX до completion,
  последовательно и офлайн.
- `VotingNarrationCheck`: очередь, паузы, отсутствие пересечений, предупреждения,
  повторные снимки, позднее восстановление, тишина во время музыкальной интриги.
- `core:check`, `server:test`, `impostorCheck`, `votingRedesignCheck`.
- `ready` — техническая готовность в рамках ранее одобренного голоса, не отметка
  индивидуального пользовательского одобрения каждой новой интонации/произношения.

Прослушать весь комплект:

```sh
./gradlew :lwjgl3:hostVoicePlaybackCheck -PimpostorVoiceReview=true --offline
```

Просмотреть сцену с финальным голосом и музыкой:

```sh
python3 tools/dev/run_impostor_preview.py -Dimpostor.preview.verdict=reveal
```

В предпросмотре: I — повторить раскрытие, F — финальное голосование,
D — раунд слов. Обычный сетевой режим озвучен автоматически.
