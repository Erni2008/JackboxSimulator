# Постановка The Impostor

Реализованы пункты 1–8 и 10 из согласованного списка. Быстрый реванш не добавлялся.

1. **Раздача ролей.** Закрытые карточки последовательно летят от стола к игрокам.
   Длительность — 1,25 секунды; после неё начинается инструкция. Собственный звук
   `assets/sounds/impostor/card_deal.wav` подключается автоматически. Пока его нет,
   используется существующий звук бумаги, без синтеза или изменения исходных файлов.
2. **Защита роли.** На телефоне роль и слово скрыты до нажатия «Показать роль».
   Их можно снова закрыть; уход из вкладки и переподключение также закрывают карточку.
   Личный сигнал импостора не играет через закрытую карточку.
3. **Первое обучение.** Короткая памятка для мирного, импостора и зрителя.
   Она не останавливает серверный таймер. «Понятно» сохраняет только отметку
   прочтения; роль и слово не записываются. «Как играть» возвращает памятку.
4. **Начало раунда.** Титр держится 1,4 секунды, добавлена подстрока и звуковой
   акцент бумаги. Переподключение не повторяет объявление.
5. **Готовность.** Ведущий видит «Слово принято» / «Ожидаем слово» под участником.
   Сервер передаёт `clueReadyIds` только ведущему в фазе ввода; сами слова не раскрываются.
6. **История.** Общий экран показывает таблицу всех раскрытых слов по игрокам и раундам.
   На телефонах таблица доступна в обсуждении и голосовании. Источник — только
   `revealedClues`, без извлечения личного слова или частных голосов.
7. **Голоса.** Пауза перед печатями — 1,7 секунды, интервал печатей — 400 мс,
   контакт — 220 мс, финальная выдержка — 0,8 секунды. Сервер и общий экран
   используют одни константы. Отображается номер раскрываемого голоса.
8. **Три финала.** После раскрытия личности появляются разные заголовки,
   палитры и состояния карточек: разоблачение, побег, разделившиеся голоса.
   Завершённый отсчёт скрывается. Телефоны сохраняют чёрный экран финала.
10. **Производительность.** Карточки используют существующие текстуры; таблица
   перестраивается только при изменении данных; неизменные телефонные таймеры
   не перестраивают DOM. Измерение общего экрана записывается в
   `lwjgl3/build/impostor-check/screenshots/performance.json`: это время CPU
   при подготовке отрисовки без обмена буферов окна, не гарантия полного FPS.

## Ручной просмотр

`./gradlew :lwjgl3:impostorPreview`

- Enter / пробел — пропустить начальную заставку после появления подсказки.
- D — начало ввода; C — симулировать принятое слово.
- R / B — раскрыть карточки / перевернуть обратно.
- F — полный финальный акт.
- 1 / 2 / 3 — сразу посмотреть разоблачение / побег / разделение голосов.
- N — сброс просмотра.

Это только инструменты просмотра; правила и исход настоящего матча задаёт сервер.

## Проверки

- `:server:test`: в том числе отсутствие `clueReadyIds` у зрителей и публичного API.
- `:lwjgl3:impostorCheck`: раздача, готовность, таблица, три финала, ввод после заставки,
  сохранение ресурсов, измерение 360 кадров после прогрева.
- `check_impostor_phone_usability.cjs`: скрытие роли, уход из вкладки, обучение,
  история без личного слова, 500 обновлений без перестроения DOM, 320/390/844.
- `check_impostor_browser.cjs` с `IMPOSTOR_FINAL_QA=1`: настоящие матчи,
  приватность, принятые слова, голосование, штампы и все варианты исхода.
- `check_impostor_audio.cjs`: закрытая роль не вызывает личный звуковой сигнал.

Мобильные размеры проверяются браузерной эмуляцией; физические телефоны
и длительные игровые сессии отдельно не измерялись.

Церемония голосования затем существенно переработана: [новый дизайн и аудит](voting-redesign.md).
