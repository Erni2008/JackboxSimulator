# Приватная подсказка импостору

Сервер один раз выбирает направление вместе с загаданным словом и передаёт
`wordHint` только авторизованному игроку с ролью IMPOSTOR. `secretWord` ему
по-прежнему не передаётся. Мирные игроки продолжают получать точное слово.
Хост, зрители, публичный просмотр комнаты и общий экран подсказку не получают.
Повторное подключение сохраняет прежнюю подсказку; закрытие игры очищает её.

Встроенный словарь использует общие направления:

| Слово | Направление |
| --- | --- |
| ЯБЛОКО | Еда |
| ОКЕАН | Природа |
| МУЗЫКА | Творчество |
| КОСМОС | Пространство |
| САМОЛЁТ | Путешествия |

Для собственного `IMPOSTOR_WORDS` можно определить `IMPOSTOR_WORD_HINTS` как JSON:

```json
{"ОГОНЬ":"Стихия","ТЕАТР":"Досуг"}
```

Если для нестандартного слова направление не задано, используется широкое
«Предмет, место или явление». Для качественного собственного набора стоит
подготовить направления ко всем словам. Подсказки длиннее 72 символов, пустые
или содержащие само загаданное слово заменяются безопасным общим вариантом.

На телефоне роль и подсказка теперь открываются сразу. Кнопка скрытия и
автоматическое скрытие при переключении вкладок убраны по просьбе пользователя.
Для импостора
используется `.textContent`, а не HTML или раскрытие поля secretWord.

Проверки: `ImpostorHintTest` (права получателей, отсутствие точного слова,
стабильность восстановления, встроенные направления) и мобильный
`check_impostor_phone_usability.cjs` (скрытие/показ/сворачивание подсказки).
