# Восстановление телефонного контроллера

## Изменения

Телефон продолжает использовать существующие WebSocket, AUTH, PING и SYNC. Новых сообщений протокола и серверных правил нет.

- `web/connection-health.js` отслеживает один ожидаемый ответ на PING. Если открытая вкладка не получает ответ за 8 секунд, существующее переподключение восстанавливает место по прежнему токену. Нормальный интервал PING — прежние 10 секунд.
- При замене соединения, выходе и потере связи срок ожидания очищается. Старый callback не может отключить новое соединение.
- Во время скрытия вкладки watchdog отключён, но прежние keepalive PING продолжаются, пока браузер разрешает фоновые таймеры. При возвращении запрашиваются SYNC и новая проверка связи. Ограничения фоновой работы iOS/Android остаются в ведении браузера.
- Событие offline сразу показывает восстановление. Экран содержит отсчёт до следующей существующей автоматической попытки и кнопку ручного повтора. Важный текст показывается сразу, без анимации появления.
- TRY AGAIN заменяет соединение без общего сброса контроллеров. LEAVE ROOM по-прежнему сбрасывает локальную сессию.

## Секретный черновик укрытия

До подтверждения выбранная ячейка сохраняется только в памяти текущего телефона. Отключение не отправляет и не подтверждает её. После переподключения черновик остаётся при той же сессии, игроке и ходе. Подтверждённый сервером выбор имеет приоритет. Новый контекст, сброс, завершение выбора или выход очищает локальный черновик.

Это не резервирование ячейки: если другой игрок занял её, прежняя серверная валидация может отклонить подтверждение. После перезагрузки страницы неподтверждённый черновик не восстанавливается из хранилища. Принятые действия восстанавливаются из серверного состояния.

## Проверки

Без браузера и дополнительных зависимостей:

```sh
node tools/checks/check_connection_health.cjs
```

Проверяются совпадающий ACK, посторонние ответы, пропущенный ответ, устаревшие таймеры, отмена и замена соединения.

Для проверки браузера запустить изолированный fixture:

```sh
./gradlew :server:impostorBrowserFixture -PimpostorManualClock=true --offline
CONTROLLER_URL=http://127.0.0.1:PORT PLAYWRIGHT_MODULE=/path/to/playwright CHROME_PATH=/path/to/chromium node tools/checks/check_connection_health.cjs
```

Тест проверяет приватность и жизненный цикл черновика, затем подключается к настоящему серверу. Намеренно пропускает исходящий PING, ждёт обнаружения неответившего соединения, проверяет восстановление того же selfId и очистку сессии при выходе. Снимок: `generated/controller-polish/reconnecting-390.png`. Fixture предназначен только для разработки; тест не открывает административных маршрутов.

Полный Cursed Boxes можно дополнительно прогнать с ручным переподключением между выбором ячейки и подтверждением:

```sh
./gradlew :lwjgl3:cursedBoxesFullRoundCheck --offline
CURSED_RECONNECT_QA=1 KEEP_OPEN=0 PLAYWRIGHT_MODULE=/path/to/playwright CHROME_PATH=/path/to/chromium node tools/checks/check_cursed_full_round.cjs
```

Проверка физических телефонов, переключения Wi-Fi/mobile data и блокировки экрана остаётся отдельным ручным шагом. При отсутствии связи результат не выдумывается и выстрел не повторяется автоматически.

## Выполненный прогон

- Проверка watchdog без браузера: успешно.
- Chromium и настоящий сервер: потерянный ответ на PING, восстановление прежнего selfId, выход и очистка таймера — успешно.
- Обработчики скрытой/видимой вкладки проверены с эмуляцией свойства hidden: фоновый PING сохраняется, watchdog отменяется, при возврате отправляется SYNC.
- Черновик: не отправляется до подтверждения, сохраняется при обрыве, уступает серверному подтверждению, очищается при сбросе и новой сессии.
- Полный Cursed Boxes с `CURSED_RECONNECT_QA=1`: успешно, включая ручной TRY AGAIN после выбора ячейки. Пять начальных вставок и два реальных выстрела сохранены, один персонаж исключён, другой выжил.
- The Impostor: все три финала и восстановление страницы прошли сетевую регрессию.
- 36 мобильных компоновок, Gradle `verifyProject`, синтаксис JS и проверка структуры — успешно.

Это проверки настольного Chromium и управляемых обрывов; они не являются проверкой настоящего переключения сетей на физических телефонах.
