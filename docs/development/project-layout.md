# Организация проекта

Исходные Java-модули и рабочие пути ресурсов libGDX сохранены. Навигация: [карта проекта](../../PROJECT_MAP.md), [документация](../README.md), [инструменты](../../tools/README.md).

## Каталоги

- `assets/` — ресурсы, используемые игрой.
- `source_assets/` — оригиналы для подготовки ресурсов; `incoming/` — новые материалы до импорта.
- `tools/assets/` — импорт и подготовка материалов.
- `tools/checks/` — проверки API, браузеров и структуры.
- `tools/dev/` — вспомогательные инструменты разработчика.
- `docs/` — документация по подсистемам.
- `generated/` — результаты проверок и визуальные материалы; `previews/` — отдельные превью.

Из корня перенесены 44 оригинальных медиафайла, 23 инструмента, 43 документа, один реестр и четыре изображения результатов. Оригинальные названия и содержимое медиа сохранены. История перемещений с контрольными суммами: `docs/assets/project-layout-moves.json`. Каталог исходников: `source_assets/catalog.json` (57 файлов).

Пути импортёров, команд, документации и генерации превью обновлены. Python-инструменты находят корень по `settings.gradle`, браузерные инструменты устанавливают рабочий каталог относительно своего расположения. Старую подробную карту сохранили как исторический документ.

## Проверки

```sh
python3 tools/checks/check_project_layout.py
./gradlew :server:check :core:check :shared:check :lwjgl3:assemble --offline --console=plain
./gradlew :lwjgl3:compileDevJava --offline --console=plain
```

Проверки структуры и Gradle прошли. Оба аудиоподготовщика запущены с новых путей из `/tmp`; 388 проверенных рабочих ресурсов остались побайтно прежними. Полный сценарий Cursed Boxes с четырьмя телефонными контроллерами прошёл после переноса браузерного инструмента: 698 проверенных кадров, один скрывающийся игрок исключён, другой выжил. После закрытия проверочного приложения сетевой порт освобождён.

Существующие изменения аудиосистемы сохранены. Игровые правила и сетевой протокол при организации файлов не изменялись. Сборочные кэши, Git-история и существующие результаты проверок не удалялись.

## Надёжность сборки

Общий `assets/assets.txt` теперь создаётся одной корневой задачей `generateAssetList`, после подготовки runtime-текстур. Модульные задачи сохранены как совместимые точки входа. Чтение Gradle-конфигурации больше не перезаписывает файл; параллельные модули не конкурируют за его запись. Список отсортирован, использует UTF-8 и `/`, исключает сам себя и обновляется только при изменении ресурсов.

Команда `./gradlew verifyProject --offline` объединяет проверку структуры, Java-проверки и сборку desktop-приложения. Она требует Python 3; существующие обычные задачи сборки остаются доступными без него. Графические и браузерные проверки запускаются отдельно.
