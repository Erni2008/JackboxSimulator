# Графика, память, поставка и телефонные контроллеры

Перед изменениями сохранено состояние в GitHub: `main`, коммит `9e4adf5` (проверки предыдущей интеграции звука). Этот документ описывает следующий блок улучшений.

## Поставка и память

`gradle/desktop-assets.gradle` подготавливает самостоятельный набор ресурсов в `lwjgl3/build/runtime-assets`. Он не включает исходные PNG, уже имеющие подготовленную замену из `runtime/sizes.properties`, редакторские `.blend` и документацию. Оригинальные ресурсы остаются в проекте. Копии bolt/shell в поставке соответствуют существующим облегчённым моделям Cursed Boxes; исходная геометрия, материалы и игровые трансформации не заменялись. Большие оригинальные модели доступны разработчикам в рабочем дереве.

Вторая музыка вопросов поставляется через подготовленную loop-копию. Шрифты, лицензии, используемые WAV, исходные персонажи и маски повреждений сохранены. Manifest `assets.txt` строится по фактическому содержимому поставки. Отсутствие подготовленной замены останавливает сборку с понятной ошибкой. `processResources` очищает выходную папку перед копированием, исключая старые файлы из предыдущих конфигураций.

`RuntimeTextures.exists()` учитывает подготовленные файлы, даже если исходный PNG не входит в поставку. Размеры исходника доступны для измеренных pivot/crop. The Impostor теперь использует существующий offline pipeline: интерфейсные PNG ограничены по длинной стороне до 1024, часы/печати до 512. Фоны остаются в исходных 1672 px. Положение стрелки рассчитывается в исходной системе координат, а не по уменьшенному bitmap. Пиксели персонажей этим pipeline не обрабатываются.

Для 23 ресурсов `ImpostorAsset` сумма `width × height × 4` уменьшена с 137,98 до 59,78 МиБ (−56,7%). Это эквивалент RGBA, а не показание VRAM драйвера. Публичный art для телефонов уменьшился примерно с 28 до 14 МиБ: сервер отдаёт подготовленные изображения по прежним URL и прежнему allowlist. Логотип уже имел нужное разрешение и остаётся оригинальным.

Полный desktop JAR сократился с приблизительно 635 до 394 МиБ (около −38%). Исходный архив до изменений измерялся округлённым `ls -lh`; точный текущий размер выводит проверка дистрибутива. Размер рабочего дерева намеренно не уменьшается удалением оригиналов.

Properties runtime-текстур теперь записываются в стабильном порядке без временной метки. Устаревшие подготовленные PNG удаляются при пересборке этого output-каталога. Дополнительные зависимости для штатной сборки не добавлены.

## Общий экран

Новый `CinematicFrame` рисует мягкое статическое затемнение краёв одним quad с маленькой текстурой 96×64, создаваемой один раз владельцем. Нет framebuffer-проходов, новых шейдеров и загрузки на выстреле. Центральная область остаётся прозрачной.

- Cursed Boxes: мягкие подложки HUD, ограничение ширины длинных имён и описаний; матрица overlay обновляется только при изменении размера окна.
- The Impostor: симметричные пылинки по обеим сторонам комнаты, статическая глубина по краям; существующие сценические переходы и персонажи сохранены.
- Загрузка Cursed Boxes: шкала из 16 сегментов, учитывающая загрузку, сборку сцены и прогрев. Пользовательские подписи вместо названий технических ресурсов; F3 показывает подробности. Ошибка обязательного ресурса оставляет доступным безопасный выход в меню. Частичная загрузка, ошибка и повторный вход освобождают ресурсы.

`CursedBoxesPerformanceCheck` теперь ждёт действительные окончания загрузки пяти патронов/выстрелов/возврата. Старый тест ошибочно ожидал разрушение на 120-м кадре. Игровые длительности ради теста не изменялись. Проверка контролирует отсутствие новых shader compile, texture upload, static buffers и роста ресурсов во время выстрелов. Цифры CPU из параллельных запусков не используются для утверждения о приросте FPS.

## Телефоны

- Часы: backing store подбирается под размер на экране и DPR до 2, максимум 512×538 вместо 1223×1286; raster до 30 раз/с, при reduced motion до одного раза/с. Скрытая вкладка и завершённая фаза прекращают работу. Абсолютный server deadline не изменён.
- Cursed Boxes: отдельная панель подтверждения, более читаемая выбранная ячейка и прежнее разделение секретного укрытия/выстрела.
- The Impostor: три карточки подозреваемых размещаются одной строкой при ширине от 375 px, с читаемым полным именем в сводке выбора. На маленьких телефонах остаются две колонки. Подтверждение ближе к карточкам.
- Поле подсказки: счётчик 0–10 букв. При открытой клавиатуре декоративные блоки скрываются, пергамент становится компактнее. Секрет, draft, ограничения и серверная проверка не меняются.
- Перо: измерения layout выполняются на вводе/resize, а не на каждом animation frame. Движение использует translate/rotate/scale; тень статична. При скрытии вкладки, reduced motion и остановке компонента RAF прекращается. Исходный PNG, положение кончика, жесты и IME сохранены.

## Проверки

```sh
./gradlew verifyProject :lwjgl3:compileDevJava --offline
./gradlew :lwjgl3:packagedAssetsCheck --offline
node tools/checks/check_countdown_budget.cjs
./gradlew :lwjgl3:impostorCheck :lwjgl3:cursedBoxesNavigationCheck --offline
./gradlew :lwjgl3:cursedBoxesCharacters -PcursedCharacterQA=true --offline
./gradlew :lwjgl3:cursedBoxesPerformanceCheck -PcursedCycles=4 -PcursedProfile=generated/tmp/polish-final.json --offline
```

`verifyProject` включает `checkDesktopDistribution`: stdlib Python сверяет SHA-256 всех 401 поставляемых файлов с JAR, корректность manifest, замены текстур/моделей и отсутствие редакторских ресурсов. `packagedAssetsCheck` запускает настоящий production JAR с dev-проверкой, из каталога build: исходная папка assets не может скрыть пропуски. Проверяются меню, все 23 ресурса The Impostor и полная сцена Cursed Boxes.

Браузерные проверки требуют Playwright/Chromium и локального `:server:impostorBrowserFixture`:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright CHROME_PATH=/path/to/chrome node tools/checks/check_parchment_browser.cjs
CONTROLLER_URL=http://127.0.0.1:PORT PLAYWRIGHT_MODULE=/path/to/playwright CHROME_PATH=/path/to/chrome node tools/checks/check_controller_presentation.cjs
PLAYWRIGHT_MODULE=/path/to/playwright CHROME_PATH=/path/to/chrome node tools/checks/check_impostor_final_browser.cjs
```

Также выполнен полный Cursed Boxes round с четырьмя настоящими телефонными клиентами: вопросы, приватное укрытие, два выстрела, layered wood/appearance2 и survivor reveal. Девять автоматических выстрелов оставляют восемь персонажей видимыми, выполняют зарядку 5+4 и отклоняют десятый выстрел.

Ограничения: браузерная проверка клавиатуры имитирует изменение visualViewport; нужны физические iPhone/Android для проверки поведения клавиатуры и субъективного качества. Обещаний роста FPS на всех GPU нет: измерены объём поставки/текстур и проверены ограничения ресурсов, а графические изменения добавляют два draw calls в Cursed Boxes. Отсутствующий ранее optional `host_check_boxes.wav` по-прежнему использует существующий subtitle fallback.

## Итог прогона 23.10.2026

Все команды выше выполнены успешно. Проверка production JAR подтвердила 401 ресурс, текущий размер 394,10 МиБ. Графический профиль Cursed Boxes: 4 цикла, 1754 кадра, медиана CPU submission 0,201 мс и p95 0,326 мс; 0 компиляций шейдеров, 0 texture upload, 0 GC в измеряемой части. Это диагностические CPU submission времена с GL-interceptor, а не FPS и не полное GPU frame time.

Проверены 36 мобильных кадров; письменный ввод, латиница/кириллица, IME, 10-буквенный лимит, reduced motion, три размера окна и освобождение writer. Во время отдельного жеста пера было два чтения offsetWidth вместо чтения на каждом кадре. Имитация открытой клавиатуры включает компактную компоновку и затем корректно восстанавливает её. Все три серверных исхода Impostor (`IMPOSTOR_CAUGHT`, `NO_CONSENSUS`, `IMPOSTOR_ESCAPED`) прошли с проверками приватности, повторов, reconnect и таймеров. Успешно проверены отсутствующая обязательная модель, отмена частичной загрузки, восстановление дисплея и повторный вход. `verifyProject :lwjgl3:compileDevJava :lwjgl3:packagedAssetsCheck`, контроль целостности 61 оригинала и `git diff --check` прошли.
