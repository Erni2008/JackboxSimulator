# Размер проекта и безопасная очистка

25 октября 2026 года рабочая папка занимала примерно 19 ГиБ. После удаления
пересоздаваемых результатов и обслуживания Git — около 7 ГиБ; точное значение
немного меняется после сборки. История Git занимает около 5,14 ГиБ оставшегося
объёма. Коммиты, резервная ветка, agent refs, reflog и текущие изменения сохранены.

## Что убрано

- Около 5,42 ГиБ: 3040 файлов сборок, дистрибутивов, локального кеша браузера,
  игнорируемых снимков проверок и кешей Python/Gradle внутри проекта.
- 8 заброшенных временных файлов Git за 18 октября, около 1,42 ГиБ.
- 1958 loose-объектов Git, уже находившихся в pack-файлах: удалены штатной
  командой `git prune-packed`.
- Оба исходных pack-файла содержали 3668 одинаковых объектов. Штатный
  `git gc --keep-largest-pack --no-prune --no-detach` убрал дублирование,
  сохранив все ссылки и отключив истечение reflog. Сжатие без потерь.

Все файлы из `assets/` и `source_assets/`, оригинальные GLB и звук, исходный код,
отслеживаемые отчёты и общая папка зависимостей `~/.gradle` сохранены. Браузер
для browser QA при необходимости потребуется установить заново; Java-сборка
продолжает работать с уже имеющимися общими зависимостями в offline-режиме.

## Повторная очистка

Закройте игровые окна и активные проверки, затем выполните из корня:

```sh
python3 tools/dev/clean_project.py
python3 tools/dev/clean_project.py --apply --report /tmp/finalanswer-cleanup.json
```

Без `--apply` утилита только считает файлы. Она отказывается удалять сборочную
папку, если внутри есть отслеживаемые файлы, и не трогает Git. В `generated/`
удаляются только неотслеживаемые снимки, видеозаписи, логи и архивы; JSON-отчёты
сохраняются. Временные файлы Git следует удалять только после отдельной проверки
их возраста и отсутствия активного процесса записи.

## Запуск без дублирования ресурсов

`lastCommandPreview` и `lastCommandPreviewCheck` используют скомпилированные
классы и исходную папку `assets/`. Они больше не требуют desktop staging и
копирования всей папки ресурсов в `lwjgl3/build/resources/main`. Компиляция
Java dev-кода зависит только от классов main, поскольку ресурсы при компиляции
не нужны. Обычная упаковка desktop JAR и остальных проверок не изменена.

```sh
./gradlew :lwjgl3:lastCommandPreview --offline
./gradlew :core:check :shared:check :server:check :lwjgl3:lastCommandPreviewCheck --offline
```

До очистки `check_project_layout.py` уже сообщал об оригинальных GLB и WAV,
добавленных в корень после создания каталога исходников. Эти оригиналы намеренно
сохранены; очистка не маскирует предупреждение изменением правил проверки.
