# The Last Command — свет и оформление сцены

30 октября 2026.

Перенастроены экспозиция, окружение, основной свет и холодный контурный источник. Число источников не увеличено. Машина стоит на низкой графитовой платформе с металлическим кольцом и восемью креплениями через InstancedMesh. Более спокойная текстура пола генерируется один раз; контактное затемнение сохранено. Это три дополнительных draw calls относительно прежнего пола и контактной тени. Новых постэффектов, внешних изображений или динамических теней не добавлено.

Для состояния READY расширенной игры создана статичная титульная заставка на существующей canvas-текстуре CRT. При PLAYING возвращается прежний renderer заданий. Обновлены латунная кнопка запуска и оформление результатов. Правила, модели корпуса и исходные текстуры не менялись.

Проверки: npm build, git diff --check; check_last_command_presentation.cjs (LOW-корпус, ACTIVE кодовой панели, idle без GPU-кадров, ray picking, desktop/mobile, без pageerror); check_last_command_resolution.cjs; новый check_last_command_art_direction.cjs (READY-заставка → запуск → реальное задание, mobile, удаление всех presentation meshes при dispose, без pageerror). Общий вид, front/rear, desktop task и mobile осмотрены. Результаты в generated/last-command-art-direction/. Измерения FPS/нагрева и испытания физических телефонов не выполнялись.
