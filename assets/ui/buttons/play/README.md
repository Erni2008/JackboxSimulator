# Изображения кнопки PLAY

- `play_up.png` — обычное состояние.
- `play.hover.png` — наведение со свечением.
- `play.pressed.png` — нажатие.

Надпись PLAY уже встроена в PNG и движется вместе с кнопкой.
Код плавно смешивает изображения, сохраняя их исходные цвета и прозрачность.
Оригиналы находятся в `core/src/main/java/com/erni/finalanswer/ui/buttons/PLAY/`.
Для запуска используются копии в этой папке ресурсов.
После замены PNG перезапусти игру.
