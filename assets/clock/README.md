# Готические часы PLAY

Исходные PNG скопированы из корня проекта без переименования. У всех есть alpha channel.
В наборе 10 файлов: clock1–clock6, clock8–clock11. Файл clock7.png отсутствует.

Используемые слои:

- clock1.png — открытый корпус без стрелки;
- clock2.png — отдельная стрелка с красным камнем;
- закрытие: clock1 → clock4 → clock5 → clock6 → clock8 → clock10 → clock11;
- clock3.png повторяет открытое положение; clock9.png близок к clock10.png, поэтому они не загружаются.

clock11.png — полностью закрытая крышка. Отсутствующий clock7.png для текущей последовательности не нужен.
Загрузчик использует реальные имена файлов. Не заменяй их на clock_01_body.png и т. п. без изменения путей.

## Настройка геометрии

`core/src/main/java/com/erni/finalanswer/ui/clock/ClockTimerActor.java`:

- размер исходного холста: 1312×1199;
- центр циферблата: (656, 598), координаты от верхнего левого угла;
- pivot красного камня стрелки: (656, 838);
- масштаб отдельной стрелки относительно корпуса: 0.30;
- радиус программного сектора: 260 исходных пикселей;
- FRAME_CENTER_Y и FRAME_SCALE — нормализация каждого кадра к общей привязке корпуса.

Вершина отдельной стрелки в PNG смотрит на XII. LibGDX вращает её на отрицательный угол:
при 20 с это -120° (IV), затем угол растёт до 0° (XII), то есть движение против часовой стрелки.
Подсветка строится отдельно от стрелки: от 90° − highlightAngle до 90° в координатах OpenGL.
На кадрах закрытия видимая стрелка уже нарисована на XII в самих исходных PNG.

Оригиналы не изменяются. Gradle готовит RGBA-копии шириной 512 px в assets/runtime/clock/.
Восемь реально загружаемых текстур занимают примерно 7.31 MiB RGBA вместо 48 MiB у полных PNG.
ShapeRenderer и текстуры создаются один раз и освобождаются вместе с PlayScreen.

## Проверка

```sh
./gradlew :lwjgl3:playPreview
```

P — пауза/продолжение; R — досрочное завершение таймера для проверки крышки;
SPACE — следующий вопрос; ESC — главное меню.
Таймер запускается по TIMER_STARTED после появления последней карточки.
До этого вопрос появляется, выдерживает паузу после озвучки и поднимается вверх.
20 с отсчёта → 0.2 с закрытия → 0.1 с паузы → 0.42 с падения.

```sh
./gradlew :core:clockCheck
./gradlew :lwjgl3:playCheck -PplayCapture=true
```

Снимки: /tmp/play-full.png, play-result.png, play-clock-closed.png,
play-clock-falling.png, play-clock-finished.png. Проверка также сравнивает число
управляемых Texture и Mesh до/после, а также отсутствие их создания при анимации.

Во время RUNNING часы слегка потряхиваются: один общий offset применяется
к корпусу, стрелке и сектору. Амплитуда — около 0.2% ширины часов, плавно
нарастает в начале и затухает перед нулём. Пауза замораживает движение;
уменьшение движения его отключает. Красный сектор затемнён до RGB (116,5,14)
при базовой alpha 0.46. Скорость стрелки и закрытие за 0.2 с не меняются.
