# Ресурсы, которые использует игра

> Медиа хранятся только локально и исключены из Git. Для нового клона нужны приватные ресурсы из вашей копии. См. [правила приватных медиа](../docs/assets/private-media.md).

Эта папка — источник ресурсов для libGDX и упаковки приложения. Браузерные контроллеры получают только разрешённые файлы из неё через `server/build.gradle`; HTTP-пути `/art/...` не зависят от расположения файлов в корне проекта.

| Папка | Содержимое |
| --- | --- |
| `backgrounds/` | Главное меню, создание комнаты, основные игровые фоны |
| `ui/buttons/` | Кнопки по назначению, с отдельными состояниями |
| `ui/windows/` | Окна, поля ввода, декоративные панели |
| `ui/fonts/` | Шрифты и лицензии |
| `clock/` | Общие часы Final Answer |
| `impostor/backgrounds/` | Фоны THE IMPOSTOR |
| `impostor/clock/` | Часы и стрелка THE IMPOSTOR |
| `impostor/envelopes/` | Конверты |
| `impostor/papers/` | Карточки и листочки общего экрана |
| `impostor/phone/` | Ресурсы телефона: `papper3dview.png`, `word_reminise.png`, `pen.png` и прежние макеты |
| `impostor/portraits/` | Рамки участников |
| `impostor/voting/` | Печать и оттиски |
| `models/` | Модели и кадры анимаций |
| `i18n/`, `questions/` | Переводы и вопросы |
| `runtime/` | Автоматически создаваемые оптимизированные копии; вручную не редактировать |

`assets.txt` создаётся сборкой. Имена существующих изображений сохраняются ради совместимости с кодом.

Неиспользуемые оригиналы и архивные копии находятся в `../source_assets/`, а не рядом с Java-классами и Gradle-файлами. Полный порядок добавления изображений: [документация](../docs/assets/README.md).

Комната ожидания: `lobby/cages/` содержит клетки и цепи, `lobby/characters/<id>/` — PNG и конфигурацию каждого персонажа. `lobby/character_presentation.json` задаёт масштаб, смещение и яркость персонажа именно внутри клетки. Исходники и запасные варианты хранятся в `source_assets/lobby/`.

Cursed Boxes: `cursed_boxes/` содержит рабочие модели, фон, эффекты, персонажей и survivor rigs; `sounds/` содержит записи по категориям (`cursed_boxes`, `cages`, `ui`, `environment`). Исходные файлы хранятся в `source_assets/cursed_boxes/`, `source_assets/shotgun/` и `source_assets/audio/`, а не в корне проекта. Подготовка — [tools/assets](../tools/assets/), каталог оригиналов — [source_assets/catalog.json](../source_assets/catalog.json).
