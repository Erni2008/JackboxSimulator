# Новые исходные материалы

Сюда можно складывать новые оригинальные модели, изображения и записи до интеграции. Они не загружаются игрой и не попадают в desktop/server-пакет.

После проверки перенесите оригинал в соответствующий раздел `source_assets/`, сохраните исходное имя и добавьте путь/контрольную сумму в `source_assets/catalog.json`, если файл нужен импортёрам. Рабочие копии создаются в `assets/` подготовительным инструментом.

Не складывайте новые PNG/WAV/GLB рядом с Gradle-файлами в корне проекта. Не заменяйте пользовательские оригиналы обработанными версиями.
