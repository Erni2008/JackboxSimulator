# Архив оригиналов

`root-imports/` содержит изображения, перенесённые из корня проекта 19 октября 2026 года, с группировкой по назначению. Файлы сохранены без изменения байтов и исходных имён. Это архив импорта, а не дополнительная папка загрузки ресурсов.

49 файлов совпадали с существующими изображениями в `assets/`. Они сохранены здесь, чтобы не удалять пользовательские оригиналы. `impostor/backgrounds/background_codeword.png` пока не используется игрой и также сохранён здесь.

Два использовавшихся из корня холста перенесены напрямую в `assets/impostor/phone/`: `papper3dview.png`, `word_reminise.png`.

Старые/новые пути и SHA-256: [реестр переноса](../../docs/assets/root-image-migration.csv). Архив не включается в приложение и не публикуется HTTP-сервером.
