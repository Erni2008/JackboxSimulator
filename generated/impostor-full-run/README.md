# Полный прогон THE IMPOSTOR

Выполнен в реальном времени: нативный общий экран, четыре активных игрока
и наблюдатель с настоящими браузерными контроллерами.

Пройдены роли, три раунда слов, подозрения, обсуждение, голосование,
четыре индивидуальные печати, музыкальное раскрытие и отложенный призрак.
После результатов дождались финальной реплики ведущего. Окна оставлены открытыми.

`host-report.json` содержит реальные счётчики запусков аудио. Во втором прогоне
каждая вступительная реплика раунда прозвучала один раз, подозрения и предупреждения
— по три раза за три раунда. Исправлен сброс очереди при повторном clearFinal
в обычных сетевых обновлениях. Проверка скрипта теперь запрещает эти повторы.

`players-report.json`: четыре подтверждения голосов, приватный звук роли
только на нужном телефоне, отсутствие ошибок JS. `host-*.png` — этапы общего
экрана, `player-*.png` — итоговые экраны телефонов (по правилам финал затемнён).

Запуск воспроизводится скриптом `tools/dev/run_impostor_audio_demo.cjs` с
локальной серверной fixture и нативным ImpostorPreviewLauncher, подключённым
к её ready.json. Используется реальное время, без advance/ускорения таймеров.

Примечание: этот полный прогон предшествовал последней правке телефона и удалению
речевой нумерации. Их отдельные проверки описаны в docs/impostor/phone-simplification.md.
