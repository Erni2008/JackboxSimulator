# Сохранённые результаты разработки

Здесь находятся визуальные превью, профили и проверенные артефакты разработки, а не исходники игры. Текущие сохранённые материалы не удалены и не пересобирались при упорядочивании.

- `previews/` — одиночные обзорные изображения UI и персонажей.
- `cursed-boxes/` — кадры, профили производительности, character/survivor-проверки.
- `*-preview/`, `cage-preview/`, `lobby-character-polish/` — персонажи и клетки.
- `candle/`, `create_room/` — обзоры графики и интерфейса.
- `distributions/` — локальные релизные архивы, игнорируются Git.
- `standalone-*/` — существующие материалы проверки упаковки.
- `tmp/` — необязательные временные результаты, игнорируются Git.

Автоматические browser/native-проверки также пишут в `<module>/build/<scenario>/`. Не переносите эти данные в `assets/`: игра не должна загружать скриншоты тестов. Новые проверки должны использовать отдельную подпапку по назначению и не создавать одиночные файлы в корне проекта.
